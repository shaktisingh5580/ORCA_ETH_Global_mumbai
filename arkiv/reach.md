# Who ORCA is for and current reach

Target users are marine researchers, research-agent operators and reviewers who need to distinguish a computed claim from independently inspectable evidence and reproduce a bounded calculation.

Current adoption is a team-operated hackathon prototype. We have no independently verified institutional customers, external production users or commercial traction to report. The initial real-data rehearsal contains two completed coordination tasks, two separately keyed providers and eight published/read-back Arkiv records. Later phases have separate gate evidence; these counts are not fabricated market-usage metrics.

The useful user journey is a research result, a producer claim, a selected assignment and a review that points to the exact signed artifact. The intentional-bias scenario makes the need understandable: one agent's altered input changes the answer, the clean-input reviewer detects it, and correction preserves the challenged history.

After the event, the intended next users are actual independently operated marine-data providers and reviewers. That requires external deployment/onboarding, institutional verification and scientific method qualification. The current local-process topology is not described as independent institutional federation.

Judges can inspect the public repository, run the read-only task query and verifier, and use the demo once its deployment is live. A public URL is not claimed before actual deployment verification. No fabricated usage statistics or deployment links are included.
